For technical & scientific nonfiction · Claude Code

Write technical books the way a press does.

Not for fiction — this is for books with claims to check. Three commands take a one-line idea through drafting, a seven-reviewer editorial panel modeled on academic peer review, and print/EPUB production — with a claim ledger that traces every prose number back to code that actually runs.

Three commands

The whole pipeline, end to end

01
/book-author

Idea → manuscript

Brief (gate) → verified sources → outline (gate) → drafted chapters with executable-chapter discipline: every printed number generated by shipped, pytest-pinned code, tracked claim-by-claim in passport.yaml.

Outputs — book/*.md, code/chNN/, SYLLABUS.md
02
/scientific-book-editor

Editorial QA

A 7-reviewer panel — the classic 5 plus an adversarial skeptic/advocate pair — independent peer review, a citation audit, and a 5-pass clarity review. Waits for your approval before touching anything.

Outputs — 4 reports, revised-book/
03
/production-book-publisher

Sellable artifacts

Print interior (Quarto/LaTeX), validated EPUB3, wrap covers with a computed spine width, PDF preflight, and a KDP compliance audit.

Outputs — dist/{ebook, paperback, validation}
Design principles

What makes it different

Each earned on a real book — see the README for the full list and the failure that motivated it.

Executable chapters

Prose can't drift from arithmetic. Every printed number is generated by shipped code — reviewers verify instead of trusting.

The claim ledger

passport.yaml tracks every prose sentence that asserts a specific number — id, check, expected value, PASS/FAIL/STALE — extending pytest pinning from tables into prose.

Adversarial review pair

A skeptic hunts for the finding that makes the other five reviewers look complacent. An advocate defends deliberate choices from being flattened into a worse, uniform voice.

Verify-then-edit

When prose contradicts a printed number, the code runs to decide which side is wrong — the ACM "Results Reproduced" idea, applied to books.

Gates are yours

Brief, outline, publishability verdict, revision policy — explicit approval points. Nothing gets applied without a yes.

Never fabricate

Unknown bibliographic details stay marked unverified. Missing ISBNs are reported absent, never placeholder-filled.
